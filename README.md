# Fern Game

## วิธีติดตั้งและรัน

### 1. Clone โปรเจค

```
git clone https://github.com/Athip11/Talestalker.git
cd Talestalker
```

### 2. ติดตั้ง library

```
pip install -r requirements.txt
```

### 3. ใส่ไฟล์ .env

วางไฟล์ .env ในโฟลเดอร์หลัก

### 4. รัน

```
python app.py
```

เปิด browser ไปที่ http://localhost:5000

### 5. รัน bg_server (ถ้าต้องการ generate background)

```
python bg_server.py
```
